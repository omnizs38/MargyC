# Clawdio — канал обновлений

Здесь лежат файлы, которые приложение спрашивает при проверке обновлений.

| Файл | Что это |
|---|---|
| `version.json` | последний релиз и последняя бета: версия, имя APK, заметки, SHA-256 |
| `Clawdio.apk` | сборка приложения |
| `catalog.json` | каталог модов (`.mcmod`) |
| `hello.mcmod` | пример мода |

Формат `version.json`:

```json
{
  "release": {"version": "1.4.0", "beta": 0, "apk": "Clawdio.apk", "notes": "Что нового",
              "sha256": "...", "size": 12345678},
  "beta":    {"version": "1.5", "beta": 1, "apk": "Clawdio_beta.apk", "notes": "...",
              "sha256": "...", "size": 12345678}
}
```

Собирается и выкладывается автоматически:

```sh
python3 tools/release.py build claude.xapk -o Clawdio.apk
python3 tools/release.py publish Clawdio.apk --notes "Что нового" --release
```

Приложение сверяет SHA-256 и ключ подписи скачанного APK: сборка, подписанная другим
ключом, поверх текущей не встанет — такую обновление не предлагает.

Свой сервер обновлений: «Моды → Обновления → Сервер обновлений» — адрес папки с теми же
файлами.
